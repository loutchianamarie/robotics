# `multi_sensor_perception` package

This is the current ROS 2 Jazzy package for the [simulation-based academic prototype](../../../README.md). The five Python nodes now subscribe to simulated sensors, publish camera or combined telemetry, and measure callback timing. The package is no longer at the original Step 1 placeholder stage.

For architecture, prerequisites, build and launch commands, test scope, and limitations, use the [repository README](../../../README.md). [`PROJECT_STEPS.md`](PROJECT_STEPS.md) is the original project plan, retained for history.
